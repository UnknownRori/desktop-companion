# Desktop Companion

Desktop Companion is a simple companion software that display cute character on top
of everything you have in your screen.

## Requirements

| Component |   Minimum                        | Recommended                                                                      |
|-----------|----------------------------------|----------------------------------------------------------------------------------|
|    OS     |   Windows, Linux, MacOs          |   Windows 90000000                                                               |
|    CPU    |   1.0 Ghz                        |   5000.0Ghz                                                                      |
|    RAM    |   200 Mb                         |   10000 Gb                                                                       |
|    GPU    |   128 Mb                         |   50000.0 Gb                                                                     |
|  Storage  |   5Mb                            |   10TB                                                                           |
|  Graphics | Hardware accelerated OpenGL (1.1)| OpenGL (555)                                                                     |
| Sound Card|   Any                            | Sound Card That Makes The Music Sound Like A Live Orchestra Even Though It's Not |

*The requirement might change over the course of development
